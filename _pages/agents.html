Protocols

Ezley implements the open commerce protocols agents need to discover, evaluate, negotiate, and transact on a marketplace.

  • MCP

    Model Context Protocol

    Server-side discovery + actions. Listings, offers, and transactions exposed as MCP tools.

    Endpoint documentation: coming soon (ETA M3)

  • ACP

    Agentic Commerce Protocol

    Payment-on-behalf-of-user via Stripe + OpenAI. Agents pay through Ezley's escrow flow with delegated authorization.

    Endpoint documentation: coming soon (ETA M9)

  • UCP

    Universal Cart Protocol

    Carts assembled and committed across categories. Agents build multi-item carts that span wedges.

    Endpoint documentation: coming soon (ETA M12)

  • AP2

    Agent Payments Protocol

    Second payment rail for agent-initiated transactions. Complements ACP.

    Endpoint documentation: coming soon (ETA M15)
