Auto-release

The buyer's chosen review window starts after handover is confirmed. Default window is {{ cfg.payments.autoReleaseHoursDefault }} hours — set per transaction at offer-accept time and immutable after that. If the window passes with no dispute opened, escrow releases to the seller automatically. Funds settle within ~9 days of buyer confirmation.
